## Overview of Automated Data Quality Management Tools Researched

### JSON Schema

- A specification used to define the expected structure and rules of a JSON document.
- Acts as a data contract between systems exchanging information through APIs.
- Ensures JSON files contain the required fields, data types, and formats.

### Azure Data Factory (ADF) Mapping Data Flows

- A cloud-based data integration and transformation service used to automate data movement and validation.
- Supports automated validation and quality checks during data ingestion.
- Can validate JSON data against expected schemas before loading into target systems.

## Key Features and Capabilities

### JSON Schema

- Defines required fields and relationships.
- Validates data types and formats.
- Supports nested JSON structures.
- Provides detailed validation errors when data does not meet requirements.
- Helps maintain consistency across API integrations.

### Azure Data Factory Data Flows

- Automatically validates incoming data during ingestion.
- Performs schema drift detection and schema validation.
- Applies business rules and transformation logic.
- Routes invalid records to error paths or quarantine locations.
- Generates monitoring and pipeline execution logs.
- Integrates with Azure-based data platforms and storage services.

## Examples of Use in the Organisation / Industry

### JSON Schema

- Used to define the expected structure of JSON API requests and responses.
- Ensures payloads contain mandatory fields and valid data types.
- Helps prevent malformed data from entering processing pipelines.

### Azure Data Factory Data Flows

- Validates JSON files before ingestion into analytical data stores.
- Applies automated quality checks as part of ETL/ELT processes.
- Redirects records that fail validation for investigation.
- Provides operational visibility through monitoring and execution reporting.

## Potential Challenges and Limitations

- JSON schemas require maintenance when API contracts change.
- Incorrectly configured validation rules may reject valid data.
- Schema version mismatches can occur between systems.
- Complex validation requirements can increase implementation effort.
- Automated validation confirms structure and format but may not identify all business logic issues.

## Best Practices and Recommendations

- Define and document JSON schemas for all API integrations.
- Store schemas and pipeline configurations in version control.
- Validate data as early as possible in the ingestion process.
- Implement clear error logging and monitoring.
- Quarantine invalid records for investigation rather than discarding them.
- Regularly review validation failures
