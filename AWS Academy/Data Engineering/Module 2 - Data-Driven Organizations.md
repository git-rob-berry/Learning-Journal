### Data-Driven Organizations

- A **data-driven organization** treats data as a **strategic asset**.
- Data should support both:
  - Major strategic decisions.
  - Everyday operational decisions.
- Effective use of data helps organizations:
  - Make **better-informed decisions**.
  - Respond faster to unexpected events.
  - Identify **new opportunities**.

### Modern Data Strategies

Organizations should **modernize, unify, and innovate** their data infrastructure.

| Strategy | Meaning |
|---|---|
| **Modernize** | Move to **cloud-based infrastructure** and **purpose-built services** to reduce operational and administrative work. |
| **Unify** | Create a **single source of truth** and make data accessible across the organization. |
| **Innovate** | Use data in new ways, particularly **AI and Machine Learning (ML)**, to discover insights and value. |

**Easy way to remember:**

**Modernize** the technology → **Unify** the data → **Innovate** with it.

### Data Analytics vs AI/ML

- Both **data analytics** and **AI/ML** can support predictions and decision-making.
- Traditional analytics generally uses defined queries, logic or rules.
- **AI/ML learns patterns from data** rather than relying entirely on programmed rules.

### Data Pipeline

The four main layers of a data pipeline are:

1. **Ingestion** – bringing data into the pipeline.
2. **Storage** – storing the collected data.
3. **Processing** – preparing data through tasks such as **cleaning and transformation**.
4. **Analysis & Visualization** – analysing processed data and communicating insights.

`Ingestion → Storage → Processing → Analysis & Visualization`

### Data Roles

**Data Engineers**
- Build and maintain **data pipelines and infrastructure**.
- Focus on moving, storing, cleaning and transforming data.

**Data Scientists**
- Use processed data to identify **patterns and insights**.
- May build statistical or **ML models** to make predictions.

### Data-Driven Problem Solving

A key principle is to **start with the business problem**, rather than immediately choosing a technical solution.

`Business Problem → Analyse Data → Form Hypothesis → Collect/Process Data → Test Hypothesis → Iterate`

### Example: Poor Online Sales

**Problem:** A retailer's online sales are below expectations.

The appropriate **first step** is to:

- Use a **Business Intelligence (BI) tool** to analyse previous sales data.
- Develop a **hypothesis** about why sales are underperforming.

This should happen before jumping into solutions such as:

- Building an ML model.
- Running A/B tests.
- Segmenting customers.
- Creating targeted offers.

These approaches might eventually be useful, but they assume a cause before one has been established.

### Exam Tip

For data-driven scenario questions:

1. Identify the **business problem**.
2. Look for wording such as **"first step"**.
3. Analyse the available data.
4. **Form a hypothesis**.
5. Then choose appropriate technologies or experiments.

**Key idea:** Don't jump straight to **AI/ML** just because it is available. Start with the business problem and determine what the data shows.

### Key Takeaways

- Treat **data as a strategic asset**.
- Use data to support decisions throughout an organization.
- Modern data strategy = **Modernize + Unify + Innovate**.
- Data pipeline = **Ingestion → Storage → Processing → Analysis & Visualization**.
- Data often requires **cleaning and transformation**.
- **AI/ML learns from data**, rather than relying entirely on predefined rules.
- Start with the **business problem**, analyse the data, form a hypothesis, then test it.
